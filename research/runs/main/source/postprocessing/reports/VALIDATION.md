# 검증 방법과 근거

본실험 전 7개 단위 검사가 통과했다. 전체 경로 개발 실행은 `runs/smoke/audit.json`에 48쌍·96세계·924질문 행의 감사 통과 기록을 남겼다. 개발 실행의 자료는 본실험 시험 분할과 Gram 동형 중복을 검사한다.

| 검사 | 독립적으로 확인한 내용 |
|---|---|
| 기존 예시 | 원본 `verify_witness.py`의 전체 부분집합 DP를 실행하고, `verification_recomputed.json`과 동봉 JSON의 모든 필드를 비교 |
| 새 정확 해법 | 새 도달 상태 DP와 별도로 구현한 전체 부분집합 DP를 8개 작은 무작위 행렬에서 비교; F와 모든 Q 일치 |
| 실제 정책 비용 | 두 기존 세계에서 IG 균등 동점 정책이 각각 659/168, 111/28과 일치 |
| 교환 완전성 | 작은 부모에서 4행 조합을 모두 조사한 Pasch 집합과 빠른 교환 열거 집합 비교 |
| 정보 통제 | 기존 쌍에서 base 특징·H2 점수 일치, 조건부 특징 차이 확인 |
| 이름 순열 | 행 순서와 질문 이름을 바꾼 뒤 특징의 불변·등변성, 같은 Gram 그룹 배정 확인 |
| 자원 제한 | 음수 시간 한도에서 미완결 상태를 남기고 최적 비용·첫 질문 라벨을 비워 두는지 확인 |
| 표준화 | 부모 가중 평균/분산과 상수 열의 안정성 확인 |

본실험의 최종 감사는 `runs/main/audit.json`을 기준으로 한다. 저장된 교환 이력을 재적용하고, 모든 쌍의 행 차수·Gram 검사, 모든 완료 최적 트리의 전체 대상 재실행, 모든 질문 특징 행의 목표값, 쌍별 base/H2 동일성, 정확 Gram 그룹의 분할 중복을 다시 확인한다. 각 크기·가족에서 결과를 보지 않고 ID로 고른 한 세계에 행·열 순열을 적용하여 정확 라벨·특징·8개 선택 모델의 예측을 비교한다.

구조 해석의 충분조건이나 일반 정리, 새로운 문헌상 최초성은 이 기계적 감사의 대상이 아니다. 본실험 해법이 모든 후보 부분집합을 저장하지 않아도, 재귀에 등장하는 모든 유효 첫 질문과 두 부분문제의 정확 최소값을 평가하므로 원래 정수 재귀식과 같다.
