# 예비실험 보고서

측정 환경: Intel(R) Core(TM) Ultra 5 226V, 논리 CPU 8개, RAM 15.54 GiB, Windows, Python 3.13.5. 측정: `runs/pilot_v2`. 모든 수치는 사용자 PC의 실제 실행 기록이다.

첫 예비 실행(`runs/pilot`) 후, 방법별 빈 캐시로 첫 질문 시간을 재측정한 실행(`runs/pilot_v2`)을 규모 결정에 사용했다. 같은 시드의 반복이므로 두 실행을 독립 표본으로 합치지 않는다.

p95는 2–10세계로 계산한 작은 예비 표본의 기술통계이며 보장된 상한이 아니다. RSS는 5ms 간격 표본과 Windows 프로세스 수명 peak를 함께 기록했다. 짧은 단계의 순간 최고값은 표본 사이에서 놓칠 수 있다. 셀마다 새 프로세스를 사용해 이전 셀의 high-water memory와 분리했다.

96×20은 ['state_limit', 'state_limit']로 미완결이었다. 이 두 세계에는 정확 라벨을 넣지 않았다. 64×16도 가능했지만 전체 정책 열거 비용이 커져 주 크기에서 제외했다. 본실험은 14×8·24×10·36×12에 부모 180개씩 두 가족, 크기 외삽 48×14 두 가족 각 80개, 가족 외삽 modular 36×12 160개로 총 1,400번 생성한다.

각 크기·가족의 정확 계산/모든 기준선/전체 특징 p95를 더해 모든 부모가 교환된다고 가정한 보수적 생성 시간 추정은 316.0초다. 모델 학습·동형 검사·파일 I/O 등은 별도다. modular는 같은 크기의 planted 비용으로 근사했으므로 그 가족의 비용 보장이 아니다. 한 번에 한 부모를 처리하고 BLAS 스레드를 1개로 제한한다.

설정은 `configs/main.json`, 코드·문서·설정 해시와 고정 시각은 `configs/main.frozen.json`에 남겼다. 본실험의 교환 효과나 시험 손실을 보기 전에 고정했다. 변경이 필요하면 기존 결과를 덮어쓰지 않고 변경 사유와 별도 실행을 남긴다.
